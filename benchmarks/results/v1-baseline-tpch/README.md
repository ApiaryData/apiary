# TPC-H-derived V1 baseline

The TPC-H-derived suite (scale factor 1) on V1 (`0e87f72`, image `apiary-v1:baseline`), recorded
after the fact for comparison with later phases: pi4-4gb limits, one node, local storage, 1
warmup + 3 timed runs. Six of the 22 queries (Q7, Q8, Q9, Q15, Q20, Q22) failed in V1 on its
hand-parsed table names and have no figure. See [`../phase-1e-tpch`](../phase-1e-tpch/README.md)
for the comparison.
